# CampusGate – Offline QR Student Verification System

**Student:** Juma Brian  
**University:** University of Kabianga  
**Programme:** BSc Computer Science (First Year)

## Overview
CampusGate is a mobile-based system that replaces traditional paper gate passes with QR codes. It allows university security officers to quickly verify students at the gate **without needing internet**.

The system consists of two offline applications:
1. **QR Generator App** – Creates QR codes containing student details
2. **QR Scanner App** – Scans the QR code and verifies if the student is valid

## Problem
Paper gate passes are easily lost, forged, and cause long queues at university gates.

## Solution
Students are issued QR codes. Security officers scan the code using a phone. The app works completely offline and immediately shows whether the student is valid.

## Features
- Generate QR codes with student details
- Scan and verify QR codes offline
- Check expiry date
- Basic digital signature for security
- Clear Valid / Invalid / Expired results
